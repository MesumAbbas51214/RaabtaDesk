Raabta Desk

Get the Raabta Desk App

Send inquiries, save shops, and manage follow-ups from one simple place.

Download Android App Open Web Version

Android users can install the APK directly. iPhone users can use the web version.

How to install on Android

  1. Download the APK.
  2. If your phone asks, allow install from Chrome or WhatsApp.
  3. Open Raabta Desk and login with your phone number.

For customers

  • Scan shop QR.
  • Login with phone number.
  • Submit inquiry.
  • Track replies and saved shops.

For businesses

  • Manage customer inquiries.
  • Receive QR leads.
  • Save WhatsApp, call, and walk-in leads.
  • Follow up with customers.

Raabta Desk is currently in pilot launch for local Pakistani shops.
